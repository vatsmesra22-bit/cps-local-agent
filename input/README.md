# input/

Put WhatsApp exports here (or let `--auto-import` copy them from Downloads):

- `.zip` export from the phone (Export chat → Include media)
- `.txt` chat export or messages copied from WhatsApp Web
- `web_capture/*.jsonl` written by the scheduled agent, with photos in `web_capture/images/`
- loose WhatsApp images (time taken from the file name)

Contents are private and are not committed.
